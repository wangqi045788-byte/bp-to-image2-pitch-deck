# PPT Studio compatibility entry

Read and follow [PPT Studio](skills/ppt-studio/SKILL.md), the full-suite coordinator. Preserve the user's actual decision, evidence, analysis, template and output contract. The default is editable PPTX with appropriate style, not a fixed Noir palette or flat-image deck.

For installed standalone use, prefer installing all eight sibling skills with `python tools/ppt.py install` and invoke `$ppt-studio`. The nested module paths remain usable when this whole repository is installed as the legacy `bp-to-image2-pitch-deck` skill.

If the user explicitly wants the original full-slide visual workflow, read [the legacy Image2 route](references/legacy-image2-workflow.md). It must not override a native-editable requirement or the general coordinator.
