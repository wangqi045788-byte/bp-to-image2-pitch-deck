# Scenario checks

Use these as practical behavior examples when reviewing the skill set:

1. **Investment with stale material.** A company-provided deck has a forecast and an old market estimate; the task asks for a current investment presentation. Keep management forecasts attributed, verify current public results and competing evidence, state valuation date/assumptions, and avoid turning an illustrative return range into a forecast. A supplied branded template controls visual design.
2. **Conflicting academic sources.** Two studies report different effects. Record both designs/populations, do not call one universal consensus, describe limits, then map question→method→findings→uncertainty→application.
3. **Operations/project status.** A milestone appears in the approved plan but is unfinished. Compare baseline with actual, preserve the in-progress status, expose dependency/risk and the decision/owner/date.
4. **Pitch with weak market data.** No authoritative TAM exists. Do not invent one. Build a transparently assumption-based range only if inputs can be supported; otherwise frame the need and mechanism without a number and log the gap.

In all four cases the selected analysis must follow the question and evidence. A color palette, fixed length, or named framework does not decide the analytical result.
