# Storyline and page map

## Common arcs

- **Decision:** answer first → evidence → alternatives/tradeoffs → recommendation and conditions → action.
- **Business/market:** company/problem → how value is created → market structure → differentiation/economics → evidence → constraints → implication.
- **Performance:** conclusion → comparable baseline → metric bridge/drivers → outlook/scenarios → decisions.
- **Research/teaching:** question/objectives → method/concepts → findings/example → limitations → application/practice.
- **Proposal/pitch:** need → affected audience → proposed mechanism → evidence/feasibility → cost/alternatives → milestones/ask/risks.
- **Project/status:** outcome required → approved baseline → delivered versus planned with variance → dependencies/risks → decision/owner/date.
- **Policy/programme:** objective and population → status quo/baseline → options/effects → distribution/cost/feasibility → safeguards and recommendation.

Select an arc only after seeing the brief. A deck may follow a sequence supplied by a client or teacher; then use the checks below to catch gaps without overwriting that structure.

## Page-map fields

`slide_number`, `audience_question`, `one_sentence_conclusion`, `evidence_ids`, `chart_table_or_image`, `visual_relationship`, `supporting_detail`, `source_citation_or_note`, `assumption_or_caveat`, `handoff`.

## Title sequence test

Copy every title into a blank outline. The sequence should:

1. answer the main question;
2. establish the most important fact and baseline;
3. explain the drivers or proof;
4. address the material alternative, risk or caveat;
5. reach an implication, action or clearly bounded open question.

Not every presentation needs all five beats. A learning deck may end with a comprehension check; a status deck may open with delivery status. Preserve the arc's purpose.

## Cut and move detail

- Remove a page if it repeats a conclusion, has no evidence/action, or adds only background the audience already knows.
- Merge pages if they answer the same audience question with the same evidence.
- Split a page if it carries two unrelated conclusions, the data become unreadable, or method needs independent explanation.
- Move supporting detail to notes/appendix if useful for audit but unnecessary to the main argument.
- Keep material definitions, qualifiers and risks visible where their omission could reverse an audience's interpretation.

Finish with a source-linked map. Each title must be supportable from its listed evidence; each important evidence item should support a title, qualify it, or answer a likely question.
