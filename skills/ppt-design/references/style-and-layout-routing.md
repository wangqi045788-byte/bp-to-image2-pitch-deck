# Match visual treatment to the job

Treat this as a choice table, not a taxonomy the user must fill in. New directions can be inferred from actual references without adding another preset.

| Direction | Useful situations | Page mechanics and typography | Common failure |
| --- | --- | --- | --- |
| Institutional / financial | Investor materials, financial results, due diligence | Clear conclusion headlines, precise units, disciplined tables and charts, restrained palette | Dense facts without a decision message; illegible footnotes |
| Consulting / strategy | Options, market entry, operating model | Comparison matrices, drivers, value chain, simple flows, scenario tables | Frameworks added merely to fill pages |
| Brand / editorial | Company portrait, culture, luxury, exhibitions | Strong photography, intentional crop, serif/sans pairing where appropriate, large quiet areas | Generic luxury effects or all-text interiors |
| Noir editorial | Explicit monochrome photographic reference | Neutral tones, directional light, restrained type and varied image scale | Dark unreadable photos or repeated hero subjects |
| Technology / product | Product launch, architecture, user journey | Genuine screenshots, architecture diagrams, use-case flows, clear interface labels | Invented UI, neon decoration replacing explanation |
| Academic / research | Paper presentation, thesis, seminar | Research question, method, reproducible figures, uncertainty, references | Beautifying away confidence intervals or limitations |
| Teaching / training | Lessons, onboarding, workshops | Worked examples, progressive concepts, comparison, checks for understanding | Copying a textbook paragraph onto every page |
| Operations / dashboard | Management review, status and performance | KPI definitions, variance, drivers, owners, next actions | RAG colors without thresholds; no action tied to metrics |
| Proposal / project | Client proposal, procurement, project planning | Need, scope, options, milestones, responsibilities, budget/assumptions | Promising deliverables or dates unsupported by inputs |
| Public / policy | Public-sector analysis, policy briefing | Neutral evidence, affected groups, options, tradeoffs, implementation | Presenting advocacy as measured causal evidence |
| Marketing / creative | Campaign, event, narrative pitch | Distinctive brand imagery, short narrative beats, concrete proof | Unsupported superlatives and incoherent visual styles |

Charts: line for ordered time trends; bar/column for category magnitudes; scatter for relationships without claiming causality; waterfall for an additive bridge only when arithmetic reconciles; stacked charts only with comparable totals; pie/doughnut only for a small valid part-to-whole set. Use a table when precise values matter more than visual trend.

Do not make a quantitative image with invented numbers. Render the real data natively and use image generation for surrounding composition only where useful. Charts/tables must retain titles, units, labels, legend meaning and source qualifiers after export.
