# Provenance and redistribution

The method and compatibility adapters were extracted from an approved local presentation workflow. Client presentations, campaign photographs, research, notes and previews are excluded from this public package.

Original helpers and guidance use the repository MIT license. The native converter is adapted through FigEdit from [PPT Master](https://github.com/hugohe3/ppt-master); MIT notices and integration provenance are retained under `vendor/`.

Bodoni Moda Editorial is a renamed static instance of [Bodoni Moda](https://github.com/google/fonts/tree/main/ofl/bodonimoda). Its SIL Open Font License, copyright and instance provenance accompany the font under `assets/fonts/`. No global font installation occurs.

Related critique methods consulted, not installed as tools:

- [taste-skill](https://github.com/senlindesign/taste-skill): explain decisions behind a reference.
- [Impeccable](https://github.com/pbakaus/impeccable): review hierarchy, typography and unnecessary decoration separately.
- [frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md): choose a specific direction appropriate to the subject.

These are primarily interface-design resources; PPT review uses slide legibility, evidence and native rendering. No remote hooks or design CLI are installed.

The launcher delegates creation to the user's Codex runtime. See [OpenAI non-interactive mode documentation](https://learn.chatgpt.com/docs/non-interactive-mode). It preserves sandbox protections, collects no credentials, and depends on tools available to the user's account.
